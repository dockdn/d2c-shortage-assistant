    and sizes. Select the sizes and quantities you
    need, then export your purchase order using
    the original NC State import template.

          Do not use Inventory by Location.

          Excel import template.

      Only NC State products with Pack records
      are used for purchase order selection.

Warehouse Reference


    

      

        
          

            Term / Location
            Meaning / Action
          

        
        
          

            SKU
            Stock Keeping Unit — identifies a specific product or variant.
          

          

            LPN
            License Plate Number — identifies a box or inventory container.
          

          

            Shelf Location
            Pickable inventory. Includes 100 and 88 building shelf locations and FM locations.
          

          

            FM LocationsPickable inventory, not storage. Count free quantity toward shortage coverage; no replenishment is needed when pickable stock covers demand.


FL LocationsNon-pickable storage. Include in replenishment pulls when needed.
Storage Location
            Non-pickable inventory that may require replenishment.
          

          

            Receiving Dock
            Inventory located in receiving; verify before requesting a pull.
          

          

            Virtual Locations
            Notify Maren. Special handling or requests may be required.
          

          

            MV-M1 / 0M1 / 0M5
            Exception locations. Review separately rather than placing them on standard replenisher sheets.
          

          

            Staging
            Exclude from normal storage pull recommendations.
          

          

            Letter.Number Locations
            Locations such as A . 10 should not automatically be treated as pickable shelf inventory.
          

          

            The Game Hats
            Use building 88 inventory only for POD hat retrieval. Exclude apparel.
          

          

            Shortage Report
            In Logiwa, go to Reports and filter by MagnaReady and Swoveralls.
